# Сторонние компоненты и данные

Код проекта распространяется по лицензии MIT (см. `LICENSE`). Ниже — то,
что взято со стороны: библиотеки, которые программа использует, и
справочные величины, которые лежат в `alchemy/data`.

## Библиотеки

| Компонент | Лицензия | Зачем |
|---|---|---|
| PySide6 (Qt for Python) | LGPLv3 | интерфейс |
| matplotlib | PSF-подобная (matplotlib license) | графики |
| numpy | BSD-3-Clause | численные операции |
| uncertainties | BSD-3-Clause | неопределённости |
| radioactivedecay | MIT | распад нуклидов |
| cantera | BSD-3-Clause | равновесие и горение газов (необязательно) |
| python-docx | MIT | экспорт в DOCX (необязательно) |
| periodictable | BSD-подобная | сверка в тестах |

**Про PySide6 отдельно.** Qt распространяется по LGPLv3. Это значит, что
при передаче кому-либо собранной сборки (`dist/`) вместе с ней нужно
отдать текст LGPLv3 и не запрещать замену библиотек Qt на другие версии.
Сам код проекта при этом остаётся под MIT: MIT касается только того, что
написано здесь, и не накладывает ограничений на Qt.

## Справочные данные

Величины в `alchemy/data` — отдельные физико-химические константы,
а не скопированные таблицы. Источники:

| Что | Откуда |
|---|---|
| Атомные массы, изотопы | IUPAC, CIAAW |
| Термохимия: ΔH°f, ΔG°f, S°, Cp | NIST-JANAF, справочник Глушко, CRC Handbook |
| Полиномы Cp(T), 950 веществ | Burcat, Ruscic — Thermodynamic Data for Combustion and Air-Pollution Use (NASA) |
| Электродные потенциалы | CRC Handbook, Latimer |
| Константы кислотности | IUPAC, справочник Лурье |
| Произведения растворимости | CRC Handbook, NIST |
| Радионуклиды | ICRP-107, AME2020, NUBASE2020 |
| Физические константы | CODATA-2018, SI-2019 |

**Оговорка.** Отдельная величина (например, «ΔH°f метана равна −74.87
кДж/моль») не является объектом авторского права: это факт. Но подборка
целиком, порядок и оформление могут охраняться как база данных. Если
собираетесь распространять справочники отдельно от программы или
в коммерческом продукте, сверьтесь с условиями первоисточников.
Для учебного и личного использования проблемы здесь нет.

У каждой величины в программе указан источник — в самом результате,
а не только в этом файле. По нему всегда видно, откуда взялось число.
