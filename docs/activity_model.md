# Точность коэффициентов активности

Проверка: стоит ли менять нашу модель активностей (Дебай — Хюккель
с поправкой Дэвиса) на что-то более серьёзное.

## Как сравнивали

Взяли pyEQL 1.7 — открытую библиотеку, которая считает активности по
Питцеру. Сравнивали средний ионный коэффициент γ± на одинаковой ионной
силе, поэтому разница — именно в модели, а не в пересчёте единиц.

```
python tools/compare_activity.py
```

## Что вышло

| Электролит | 0.1 моль/кг | 0.5 | 1.0 | 2.0 |
|---|---|---|---|---|
| NaCl | +0.5 % | +7.6 % | +20 % | +52 % |
| KCl | +1.6 % | +13 % | +30 % | +77 % |
| HCl | −1.5 % | −2.9 % | −2.4 % | +0.1 % |
| CaCl₂ | +3.6 % | +77 % | +279 % | +1578 % |
| Na₂SO₄ | +8.0 % | +66 % | +194 % | +821 % |
| MgSO₄ | +74 % | +1341 % | +22956 % | +5 418 291 % |

Числа — наше отклонение от Питцера.

## Выводы

**До 0.5 моль/кг модель годится.** Расхождение в пределах 8 % для 1:1
солей и около 4 % для CaCl₂. Для школьных задач этого хватает с запасом.

**Выше 1 моль/кг — нет.** Двадцати процентов на хлориде натрия никто
не ждал: реальные γ± падают с ростом концентрации, а формула Дэвиса
начинает их разворачивать обратно.

**Двухзарядные соли — катастрофа.** У MgSO₄ при 2 моль/кг наша формула
выдаёт γ± = 2456. Настоящее значение — 0.045. Это не «приблизительно»,
это мусор.

**Соляной кислоте повезло.** Для H⁺ у нас эффективный диаметр сильно
завышен (ион гидратирован), и это случайно компенсирует ошибку. Совпадение
по всей шкале — от 0.1 до 2 моль/кг в пределах 3 %. Приятно, но это
совпадение, а не заслуга модели.

## Что сделано

Политика одна, но у неё три режима — по зонам применимости.

| Зона | Ионная сила | Модель | Поведение |
|---|---|---|---|
| 1 | до 0.001 | предельный закон | считаем молча, погрешность около 1 % |
| 2 | 0.001–0.1 | Дебай — Хюккель с размером иона | считаем молча, до 3 % |
| 3 | 0.1–0.5 | формула Дэвиса | предупреждение с цифрой: до 8 % |
| 4 | больше 0.5 | экстраполяция | громкое предупреждение: десятки процентов |
| 5 | γ > 5 | — | отказ с объяснением |

В каждом результате появилась строка «Модель активностей: <название>,
ожидаемая погрешность γ до N %». Не надо гадать, чему верить.

Для интерфейса и ИИ-чата есть `activity_report(charge, I)` — возвращает
коэффициент, зону, погрешность и признак «годится ли».

Молча выдать 2456 — хуже, чем отказать. Это ровно тот принцип, на
котором стоит проект.

## Что можно дальше

Питцер требует параметров взаимодействия для каждой пары ионов. Для
школьного набора это NaCl, KCl, CaCl₂, Na₂SO₄, MgSO₄ — пять солей,
около тридцати чисел. Взять их можно из публикаций Питцера и справочника
CRC, но это отдельная работа с источниками, а не быстрая правка.

Альтернатива проще: модель SIT (specific ion interaction theory) — один
параметр на пару ионов, точность до I ≈ 3. Но и она требует таблицы
параметров.

Пока решено не тащить pyEQL в приложение: он тянет pymatgen, boto3 и ещё
десяток пакетов, а сборка должна оставаться лёгкой и офлайновой.
