# ТЗ: промо-ролик Alchemy для TikTok

Документ для генерации одним заходом. Всё, что нужно исполнителю, лежит здесь:
тексты дословно, тайминги, цвета, анимации, критерии приёмки. Домысливать
ничего не надо, а что домыслишь — то и переделывать.

---

## 1. Задача

Промо-ролик химического калькулятора Alchemy. Формат — вертикальное видео
для TikTok.

**Цель одна: набрать просмотры.** Ролик не продаёт подписку, не ведёт на сайт
и не обязан приводить установки. Он должен остановить скролл, досмотреть до
конца и, в идеале, пересмотреть.

Из этого следуют три вещи, которые важнее красоты:

1. **Первая секунда решает.** Если в первом кадре нет интриги, дальше не
   смотрит никто. Крючок виден сразу, без разгона.
2. **Досматриваемость важнее глубины.** TikTok продвигает то, что смотрят до
   конца. Простая мысль с плотным монтажом сильнее глубокой с медленным входом.
3. **Ролик должен выдержать пересмотр.** На втором просмотре замечают детали,
   поэтому в кадре всегда что-то движется.

**Главная мысль, которую зритель должен унести за 20 секунд:**

> Есть калькулятор, который считает химию за тебя и не врёт. Если не знает —
> говорит, что не знает.

**Аудитория.** 15–22 года, школьники и первокурсники, готовятся к ЕГЭ или
закрывают лабораторные. Смотрят TikTok на скорости 2×, звук часто выключен,
поэтому всё важное должно читаться текстом.

**Метрики, по которым судим результат:**

| Метрика | Порог |
|---|---|
| Удержание на 3-й секунде | больше 60% |
| Досматриваемость | больше 35% |
| Пересмотры | больше 5% |
| Среднее время просмотра | больше 12 секунд из 22 |

Если удержание ниже 60% — виноват первый кадр, переделывать нужно только его.
Если удержание хорошее, а досматриваемость низкая — провисает середина,
сцены 3 и 4.

## 3. Стек и ограничения

Один файл `alchemy-promo.html`. Открывается двойным щелчком, играет сам,
интернет не нужен.

**Можно:**
- HTML, CSS-анимации, CSS-переменные, `@keyframes`
- Canvas 2D для частиц и «пляшущих» цифр
- WebAudio API для звука (синтез, без файлов)
- Встроенные шрифты только системные, либо `@font-face` с base64 — но не
  больше 300 КБ на шрифт
- JS без фреймворков, чистый

**Нельзя:**
- внешние ссылки, CDN, Google Fonts, импорт картинок
- видео- и аудиофайлы
- сборка, npm, транспиляция: файл должен работать как есть
- `alert`, `confirm`, автоплей со звуком без клика (браузер заблокирует)

**Обязательное поведение:**
- при открытии — экран с кнопкой «▶ Смотреть»; по клику запускается звук
  и таймлайн (это обход блокировки автоплея)
- после финала — кнопка «↻ Ещё раз»
- клавиша `R` перезапускает, `Пробел` ставит на паузу, `S` — покадрово
- вёрстка масштабируется под окно, но сцена всегда остаётся 1080×1920
  (через `transform: scale()`), чтобы запись с экрана была чёткой
- весь таймлайн на одном `requestAnimationFrame`, все элементы управляются
  от одного «часового» значения `t` в миллисекундах. Никаких `setTimeout` —
  они рассинхронизируются при записи

## 4. Раскадровка

Тексты даны дословно. Менять слова нельзя, менять длину пауз можно в пределах
±200 мс.

### Сцена 1 — крючок (0.0 – 2.6 с)

Фон чёрный. По центру белым, крупно, `clamp` до 96 px, шрифт жирный:

```
ЭТО УРАВНИВАЮТ
20 МИНУТ НА ДОСКЕ
```

Слова вылетают по одному: «ЭТО» на 0.0, «УРАВНИВАЮТ» на 0.15, «20 МИНУТ»
на 0.45, «НА ДОСКЕ» на 0.75. Каждое — с лёгким ударом: `scale` от 1.25 к 1.0
за 120 мс, `ease-out`.

На 1.9 с сверху наползает уравнение моноширинным, серым #8a8a8a, 28 px,
разбитое на три строки:

```
10 K4[Fe(CN)6] + 122 KMnO4 + 299 H2SO4
→ 162 KHSO4 + 5 Fe2(SO4)3
+ 122 MnSO4 + 60 HNO3 + 60 CO2 + 188 H2O
```

Оно должно быть длинным и пугающим — это и есть крючок.

### Сцена 2 — решение (2.6 – 5.4 с)

Уравнение поднимается вверх и уменьшается до 22 px, остаётся на фоне серым.

По центру появляется синяя плашка #2D7FF9 с белым текстом 72 px:

```
0.02 СЕКУНДЫ
```

Цифра «0.02» набирается счётчиком от `99.99` к `0.02` за 400 мс. Плашка
въезжает снизу на 40 px с `ease-out`.

Под ней на 3.9 с мелким #a0a0a0, 32 px:

```
это не магия, это метод Гаусса
```

### Сцена 3 — что внутри (5.4 – 9.4 с)

Быстрый монтаж. Четыре «карточки» меняют друг друга каждые 0.9 с: въезжают
справа, уезжают влево, лёгкий наклон 2°.

Каждая карточка: тёмный прямоугольник #16181d, слева горизонтальная полоса
акцента #2D7FF9 высотой 4 px во всю ширину, внутри крупно белым название
модуля и мелко серым — что считает.

| Карточка | Заголовок | Подпись |
|---|---|---|
| 1 | Молярная масса | CuSO4·5H2O → 249.677 |
| 2 | Уравнивание реакций | масса и заряд сходятся точно |
| 3 | pH и равновесия | активности, а не приближение |
| 4 | Органика | класс по формуле, изомеры, сгорание |

На 8.6 с все четыре сжимаются в строку из четырёх точек и цифру:

```
35 МОДУЛЕЙ
```

### Сцена 4 — доверие (9.4 – 13.0 с)

Фон светлеет до #1b1e24. По центру счётчик, моноширинный, 140 px, белый:

```
1017
```

Крутится от 0 до 1017 за 1.4 с с `ease-out`, цифры дрожат по вертикали на
±2 px (эффект «одометра»).

Под ним на 10.6 с, 40 px:

```
ТЕСТОВ
```

И на 11.4 с мелким, серым, по одной строке каждые 0.25 с:

```
тепловые эффекты
pH растворов
константы равновесия
электродные потенциалы
```

### Сцена 5 — характер (13.0 – 17.4 с)

Самая важная сцена. Фон возвращается к чёрному, всё лишнее исчезает.

На 13.0 с по центру 56 px белым:

```
СПРОСИ C3H6
```

На 13.8 с — ответ, и он нарочно неудобный, 44 px, серым #b0b0b0:

```
пропен или циклопропан
```

На 14.6 с вспыхивает белым, 72 px, жирным:

```
ПО ФОРМУЛЕ
НЕ РАЗЛИЧИТЬ
```

На 15.8 с ниже, 34 px:

```
программа так и скажет
```

На 16.4 с совсем мелким, #8a8a8a:

```
лучше откажет, чем соврёт
```

### Сцена 6 — подпись (17.4 – 20.2 с)

Чёрный. По центру крупно, трекинг широкий:

```
ALCHEMY
```

Справа от названия — плашка беты: квадрат 44×44, рамка 2 px #4a4a4a,
внутри буква `β` цветом #9a9a9a. Ровно как в программе, не красная.

На 18.4 с под названием 30 px серым:

```
считает локально, интернет не нужен
```

На 19.2 с мелким:

```
бесплатно
```

### Сцена 7 — финал (20.2 – 22.0 с)

Всё гаснет, кроме строки 40 px по центру:

```
ищи Alchemy
```

Ничего больше. Ни ссылок, ни описаний, ни призывов: ролик ищут по названию
в самом TikTok, и любая строчка под названием только ослабляет кадр.
Последние 0.5 с — статичный кадр. Обязательно: TikTok показывает превью
по первому кадру, но зацикливает по последнему, и оно должно быть читаемым.

## 5. Визуальный стиль

Палитра взята из самой программы, чтобы ролик и приложение выглядели одним
продуктом.

| Роль | Цвет |
|---|---|
| фон | `#0d0f12` |
| фон карточек | `#16181d` |
| основной текст | `#ffffff` |
| вторичный текст | `#b0b0b0` |
| подписи | `#8a8a8a` |
| акцент | `#2D7FF9` |
| рамки | `#4a4a4a` |

Шрифты — системные, без загрузки: `"Segoe UI", system-ui, sans-serif` для
текста, `"Cascadia Mono", "Consolas", monospace` для формул и цифр.

Правила:
- никаких градиентов-«стекляшек» и неона
- тени только под крупным текстом, мягкие, чёрные, `blur 24`, `opacity 0.6`
- сетка: всё по центру, отступы 120 px по бокам
- формулы всегда моноширинным: это подчёркивает, что перед нами расчёт,
  а не картинка

## 6. Звук

Синтез через WebAudio, без файлов. Три слоя:

1. **Низкий гул** под всем роликом: синус 55 Гц, громкость 0.04, плавное
   появление за 1 с.
2. **Удар на появление** каждой важной надписи: короткий шум-всплеск плюс
   синус 180 Гц, затухание 90 мс. Так звучат сцены 1, 2, 5.
3. **Щелчок счётчика** на сцене 4: квадратная волна 1200 Гц, 8 мс, громкость
   0.06, на каждые 25 единиц счёта.

На 2.6 с и на 10.0 с — короткая пауза в гуле (30 мс тишины): это делает
монтаж резче.

Максимальная суммарная громкость — не выше −6 дБ, чтобы TikTok не резал
и не клиппировал.

## 7. Что запрещено

Это важнее списка «что можно», потому что именно здесь ролики портятся.

- **Никаких лиц, рук и «человека за компьютером».** Ролик про программу.
- **Никаких стоковых кадров с пробирками.** Химия здесь — формулы, а не
  цветная жидкость.
- **Никаких эмодзи в кадре.** Ни одного.
- **Никаких обещаний оценки.** Не «сдай ЕГЭ на 100», а «посчитает за тебя».
- **Никаких выдуманных чисел.** Всё, что написано на экране, взято из ТЗ:
  0.02 с, 35 модулей, 1017 тестов, 249.677, C3H6.
- **Не объяснять, как пользоваться.** Двадцать секунд на объяснение
  интерфейса — потерянные двадцать секунд.
- **Не писать «нейросеть» ни в каком виде.** Это инструмент расчёта,
  и слово тянет за собой не тот разговор.
- **Не смягчать финальную сцену.** Никаких «подпишись», «поставь лайк»,
  «перейди по ссылке в шапке профиля». Только «ищи Alchemy».

## 8. Свобода действий

Раздел существует, чтобы исполнитель не боялся делать хорошо. ТЗ задаёт
смысл, числа и рамки, а форму можно менять.

### Что можно менять свободно

- **Порядок сцен** внутри середины. Сцены 1 и 7 фиксированы: крючок и подпись.
  Остальные пять можно переставлять, если так лучше держится ритм.
- **Длительность сцен** в пределах ±400 мс, пока сумма остаётся в рамках
  18–30 секунд. Двадцать две — ориентир, а не догма.
- **Визуальные приёмы.** Движение, масштаб, разлёт частиц, «печатная машинка»,
  глитч, наезд камеры, разрезание текста, кинетическая типографика — всё
  это разрешено. Единственное условие: приём должен работать на смысл,
  а не украшать пустоту.
- **Переходы.** Склейки, вспышки, сдвиги, размытие — на выбор. Резкая склейка
  обычно лучше плавной: она держит темп.
- **Добавлять микросцены** на 300–600 мс между смысловыми блоками. Часто
  именно они спасают провисание.
- **Звук.** Если предложишь лучше трёхслойной схемы из раздела 6 — бери лучше.
  Условие: без файлов, только синтез, громкость не выше −6 дБ.
- **Копирайт в мелочах.** Подписи вроде «это не магия, это метод Гаусса»
  можно заменить своими, если они короче и злее. Главное — не длиннее
  и не мягче.
- **Тон.** Ирония, сухость, лёгкое хамство — по вкусу. Унылая вежливость
  запрещена.

### Что нельзя менять ни при каких условиях

- **Числа.** 0.02, 35, 1017, 249.677, C3H6 — взяты из проверенных расчётов.
  Выдуманное число в кадре = брак.
- **Длительность больше 30 секунд.** TikTok режет досмотры на длинном.
- **Вертикаль.** Горизонтальный кадр в ленте выглядит как реклама.
- **Список запретов из раздела 7.**

### Три варианта крючка

Первый кадр решает всё, поэтому сделай три версии сцены 1 и выведи их
переключателем в углу экрана. Потом выберешь по удержанию.

| Вариант | Первый кадр | Кому заходит |
|---|---|---|
| A | «ЭТО УРАВНИВАЮТ 20 МИНУТ НА ДОСКЕ» | тем, кто мучился сам |
| B | «КАЛЬКУЛЯТОР, КОТОРЫЙ ОТКАЗЫВАЕТСЯ ВРАТЬ» | тем, кто устал от вранья |
| C | уравнение без слов, коэффициенты проявляются сами | тем, кто любит «смотри, как оно само» |

Переключатель — три маленькие точки в правом верхнем углу. По клику
перезапуск с выбранного варианта.

### Чего избегать, даже если кажется эффектным

- **Слишком много текста в одном кадре.** Больше двух строк — уже не читают.
- **Мелкого шрифта ради «стиля».** На телефоне 26 px — это минимум.
- **Долгого статичного кадра.** Больше полусекунды без движения — потеря.
- **Объяснения интерфейса.** Скриншоты программы хороши на две секунды,
  не больше.
- **Финального призыва подписаться.** Он снижает досмотры у новой аудитории
  и выглядит как реклама.

## 9. Критерии приёмки

Ролик принимается, если:

1. Файл открывается и играет без сервера, без интернета, из локальной папки.
2. Ни одного внешнего запроса в Network — проверяется в DevTools.
3. Все семь сцен выходят на своих таймингах с точностью ±100 мс.
4. Все тексты из раздела 4 совпадают дословно, включая регистр букв.
5. Звук появляется только после клика по «Смотреть».
6. `R` перезапускает, `Пробел` ставит паузу.
7. После финала виден повтор.
8. Размер файла меньше 400 КБ.
9. При записи экрана в 1080×1920 текст читается без масштабирования,
   включая мелкие подписи 26 px.
10. Три варианта крючка переключаются и перезапускают ролик.
11. В каждом кадре что-то движется: статичных пауз длиннее полусекунды нет.

## 10. Как из этого сделать видео

Сам файл — не видео, а движок ролика. Запись:

1. Открыть `alchemy-promo.html` в Chrome.
2. `F12` → `Ctrl+Shift+P` → `Capture full size screenshot` — для превью.
3. Для самой записи: `Win+G` (Xbox Game Bar) или OBS, источник — окно
   браузера, размер 1080×1920, 60 кадров, битрейт 12 Мбит/с.
4. Нажать «Смотреть», записать один проход целиком.
5. Экспорт MP4 (H.264), залить в TikTok.

Обрезка не нужна: длительность уже 22 секунды, тайминги выверены.

```
Требования к результату:

- сцена 1080x1920, масштабируется под окно через transform: scale();

- палитра и шрифты из раздела 5;
- список запретов из раздела 7 соблюсти буквально;
- пользуйся свободой из раздела 8: переставляй середину, меняй приёмы,

- сделай три варианта первого кадра с переключателем из раздела 8;
- в конце добавь ненавязчивую подпись в углу: «ALCHEMY β» мелким шрифтом.

Проверь перед сдачей критерии приёмки из раздела 8 и напиши, что выполнено,
а что нет.
```

## 12. Если понадобится вторая версия

Первая — про «считает быстро». Вторая может быть про «считает честно»:
ролик из одних отказов программы, где она отказывается отвечать на некорректные
задачи и объясняет почему. Это реже, чем «смотри как быстро», и поэтому лучше
запоминается.

Третья — про легендарную реакцию: двадцать секунд, как коэффициенты
считаются сами, без единого слова про программу. Название только в конце.
