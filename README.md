# Alchemy — химический калькулятор

Расчётная программа по химии с собственной справочной базой данных и
проверяемыми результатами. Работает офлайн, не требует интернета и не
подключает никаких ИИ-сервисов: всё считается локальными движками.

## Запуск

```
python main.py
```

Если чего-то не хватает, программа сама скажет, что установить.

## Что умеет

Функции разделены на два блока в левом меню.

## Что изменилось по сравнению с прежней версией

Прежняя версия лежит в папке `_legacy` и осталась рабочей. Главные отличия:

**Появилась справочная база.** Раньше все числа вводились руками. Теперь есть
термохимические данные, электродные потенциалы, константы кислотности,
произведения растворимости, плотности растворов, физические свойства
растворителей и полная таблица элементов.

**Расчёты убраны из интерфейса в отдельный слой.** Движки в `alchemy/engines`
не зависят от tkinter, их можно использовать в скриптах и тестах. Раньше
часть формул дублировалась прямо во вкладках, и копии успели разойтись.

**Учтены активности и температура.** pH считается через активности ионов,
а не по формуле pH = −lg C. Учтена температурная зависимость ионного
произведения воды: при 100 °C нейтральная среда имеет pH 6.14, а не 7.

**Каждый результат объясняется.** Вместе с числом показываются модель,
допущения, ход расчёта, предупреждения о границах применимости и ссылки
на источники данных.

**Единицы проверяются.** Давление, температура, объём вводятся с единицами
и переводятся; попытка подставить паскали туда, где ожидаются атмосферы,
приводит к понятному результату, а не к ошибке на пять порядков.

## Движки можно использовать отдельно

```python
from alchemy.engines import thermo, acidbase, balancer

# Тепловой эффект реакции по справочным данным
print(thermo.reaction_enthalpy("H2 + O2 = H2O(ж)").numeric())
# -571.66

# pH уксусной кислоты с учётом активностей
print(acidbase.ph_of_acid("CH3COOH", 0.1).numeric())
# 2.89

# Уравнивание окислительно-восстановительной реакции
print(balancer.balance("KMnO4 + HCl = KCl + MnCl2 + Cl2 + H2O").value)
# 2KMnO4 + 16HCl → 2KCl + 2MnCl2 + 5Cl2 + 8H2O
```

## Как записывать формулы

Программа понимает обычную химическую запись и несколько её вариантов.
Заряд можно указывать тремя способами, все они равнозначны:

```
MnO4-      обычная запись
MnO4^-     с явной крышкой
MnO4{-}    в фигурных скобках — самый однозначный
```

Три формы появились не для красоты. Запись «Fe3+» и «NO3-» устроена
одинаково, но означает разное: ион железа(III) с зарядом +3 и нитрат
с индексом 3 и зарядом −1. Разбираются они по составу:

| Запись | Что означает | Правило |
|---|---|---|
| `Fe3+` | Fe³⁺ | один элемент — цифры это заряд |
| `Ca2+` | Ca²⁺ | то же |
| `NO3-` | NO₃⁻ | несколько элементов, одна цифра — это индекс |
| `MnO4-` | MnO₄⁻ | то же |
| `NH4+` | NH₄⁺ | то же |
| `SO42-` | SO₄²⁻ | несколько элементов, две цифры — последняя заряд |
| `Cr2O72-` | Cr₂O₇²⁻ | то же |
| `O2{-}` | O₂⁻ | скобки снимают любую двойственность |

Правило покрывает всю обычную химическую запись. Но там, где смысл
действительно неоднозначен (например «O2-»: то ли O²⁻, то ли надпероксид
O₂⁻), надёжнее писать явно: `O{2-}`, чтобы заряд был 2, или `O2{-}`,
чтобы заряд был 1 при индексе 2.

Ещё несколько форм, которые понимает разбор:

```
CuSO4*5H2O     кристаллогидрат, звёздочка
CuSO4·5H2O     он же, с точкой
CuSO4.5H2O     он же, с точкой в роли разделителя
CuSO4 5H2O     он же, через пробел
Ca(OH)2        скобки с индексом
[Cu(NH3)4]SO4  комплекс в квадратных скобках
Fe2O3(тв)      агрегатное состояние
2H2O           стехиометрический коэффициент
0.5O2          дробный коэффициент
e-, 5e-        электрон в полуреакции
SO4²⁻          надстрочные цифры
```

## Источники данных

- Атомные массы и изотопы: IUPAC, CIAAW
- Термохимия: NIST-JANAF, справочник Глушко, CRC Handbook
- Полиномы Cp(T): Alexander Burcat, Branko Ruscic, Thermodynamic Data
  for Combustion and Air-Pollution Use (NASA, 950 веществ)
- Электродные потенциалы: CRC Handbook, Latimer
- Константы кислотности: IUPAC, справочник Лурье
- Произведения растворимости: CRC Handbook, NIST
- Радионуклиды: ICRP-107, AME2020, NUBASE2020 (через radioactivedecay)
- Физические константы: CODATA-2018, SI-2019

Источник указывается в каждом результате, где используются справочные данные.

## Что даёт подключение библиотек

Три библиотеки закрывают то, что раньше считалось вручную и потому
приближённо.

**Теплоёмкость как функция температуры.** В компактном справочнике Cp
хранится одним числом при 298 К, поэтому нагрев до 1500 К считался
с постоянной теплоёмкостью. Теперь для 950 веществ есть полиномы NASA
из базы Burcat: энтальпия и энтропия интегрируются по температуре,
и тепловой эффект при 1000 К совпадает с таблицами JANAF. Если для
какого-то участника полиномов нет, программа откатывается к постоянной Cp
и предупреждает об этом.

**Неопределённость с учётом корреляций.** Раньше все величины считались
независимыми, поэтому разность двух одинаковых величин давала погрешность
в √2 раза больше одиночной. Теперь повторное использование одной величины
учитывается: разность тождественно равных величин имеет нулевую
погрешность, а произведение величины на себя — 2·x·σ вместо √2·x·σ.

**Распад настоящих нуклидов.** Прежде цепочка распада решалась численно
по списку периодов полураспада и ничего не знала о ветвлениях. Теперь
доступны 1252 изотопа с реальными периодами, каналами распада
и метастабильными состояниями: распад Co-60 даёт Ni-60, а U-238 за
4.5 млрд лет проходит всю цепочку до стабильного Pb-206.

## Пересборка справочников

Данные лежат снимками, поэтому программа не зависит от сторонних библиотек
во время работы. Обновить снимки можно двумя командами.

Таблица элементов (требуется `mendeleev`):

```
python tools/build_elements.py
```

Полиномы Cp(T) (требуется `thermochem`, из него берётся файл BURCAT_THR.xml):

```
python tools/build_thermo_polynomials.py
```

Второй скрипт можно запустить и по явному пути к файлу базы:

```
python tools/build_thermo_polynomials.py --xml путь/к/BURCAT_THR.xml
```
