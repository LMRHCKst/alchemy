# Alchemy — химический калькулятор

Калькулятор по химии, который считает то, что можно проверить. Справочники
лежат в комплекте, интернет не нужен. ИИ-сервисов внутри нет, только свои
движки.

## Авторы

**stffbn4k** — проект: что считаем и зачем.

**Диси** (DeepSeek AI), инженер-расчётчик — расчёты, движки, интерфейс.
За числа в этой программе отвечаю я.

Она умеет отказывать. Нет вещества в справочнике, скажет об этом и не
подставит похожее. Модель неприменима, тоже скажет, и покажет, где
кончается её область.

Тестов 878 на 32 модуля. Если ответ расходится с бумагой, это моя ошибка,
а не твоя.

## Запуск

```
python main.py
```

Не хватает библиотеки или справочника — скажет, чего именно. Молча падать
не будет.

Интерфейс на Qt. Прежняя версия на tkinter удалена вместе со слоем
совместимости: она тянула за собой лишний код, а расчёты в обеих и так
совпадали.

## Что поменялось относительно прежней версии

Прежняя лежит в `_legacy`, осталась рабочей. Отличия такие.

**Появились справочники.** Раньше числа вводились руками, и проверить их было
нечем. Теперь есть термохимия, электродные потенциалы, константы кислотности,
произведения растворимости, плотности растворов, свойства растворителей
и полная таблица элементов.

**Расчёты вынесены из интерфейса.** Движки в `alchemy/engines` про tkinter
не знают. Раньше часть формул дублировалась прямо во вкладках, и копии успели
разойтись — одна давала pH −1.08 там, где модель вообще неприменима.

**Учтены активности и температура.** pH считается через активности ионов,
а не по формуле pH = −lg C. Ионное произведение воды зависит от температуры:
при 100 °C нейтральная среда имеет pH 6.14, а не 7.

**Каждый результат объясняется.** Вместе с числом идут модель, допущения, ход
расчёта, предупреждения о границах применимости и ссылки на источники.

**Единицы проверяются.** Давление, температура и объём вводятся с единицами
и переводятся. Подставить паскали туда, где ждут атмосферы, не выйдет —
получишь понятный ответ, а не ошибку на пять порядков.

## Движки можно звать без интерфейса

```python
from alchemy.engines import thermo, acidbase, balancer

# Тепловой эффект реакции по справочным данным
print(thermo.reaction_enthalpy("H2 + O2 = H2O(ж)").numeric())
# -571.66

# pH уксусной кислоты с учётом активностей
print(acidbase.ph_of_acid("CH3COOH", 0.1).numeric())
# 2.89

# Уравнивание окислительно-восстановительной реакции
print(balancer.balance("KMnO4 + HCl = KCl + MnCl2 + Cl2 + H2O").value)
# 2KMnO4 + 16HCl → 2KCl + 2MnCl2 + 5Cl2 + 8H2O
```

## Как записывать формулы

Заряд понимается в трёх видах, все равнозначны:

```
MnO4-      обычная запись
MnO4^-     с явной крышкой
MnO4{-}    в фигурных скобках — самый однозначный
```

Три формы нужны не для красоты. «Fe3+» и «NO3-» устроены одинаково, а значат
разное: ион железа(III) с зарядом +3 и нитрат с индексом 3 и зарядом −1.
Разбираются по составу:

| Запись | Что означает | Правило |
|---|---|---|
| `Fe3+` | Fe³⁺ | один элемент — цифры это заряд |
| `Ca2+` | Ca²⁺ | то же |
| `NO3-` | NO₃⁻ | несколько элементов, одна цифра — это индекс |
| `MnO4-` | MnO₄⁻ | то же |
| `NH4+` | NH₄⁺ | то же |
| `SO42-` | SO₄²⁻ | несколько элементов, две цифры — последняя заряд |
| `Cr2O72-` | Cr₂O₇²⁻ | то же |
| `O2{-}` | O₂⁻ | скобки снимают любую двойственность |

Правило закрывает всю обычную запись. Где смысл правда двусмысленный
(«O2-» — то ли O²⁻, то ли надпероксид O₂⁻), пиши явно: `O{2-}` для заряда 2
или `O2{-}` для заряда 1 при индексе 2.

Остальное, что понимает разбор:

```
CuSO4*5H2O     кристаллогидрат, звёздочка
CuSO4·5H2O     он же, с точкой
CuSO4.5H2O     он же, с точкой в роли разделителя
CuSO4 5H2O     он же, через пробел
Ca(OH)2        скобки с индексом
[Cu(NH3)4]SO4  комплекс в квадратных скобках
Fe2O3(тв)      агрегатное состояние
2H2O           стехиометрический коэффициент
0.5O2          дробный коэффициент
e-, 5e-        электрон в полуреакции
SO4²⁻          надстрочные цифры
```

## Режим Cantera: равновесие и горение газов

Отдельная вкладка, которая работает только если установлена библиотека
cantera. Остальные 31 модуль от неё не зависят.

Что даёт:

- **свойства газовой смеси** при заданных температуре и давлении: плотность,
  теплоёмкости cp и cv, показатель адиабаты, энтальпия, энтропия, вязкость,
  теплопроводность, число Прандтля;
- **равновесный состав** газовой смеси при постоянных T и P;
- **адиабатическая температура горения** — метан в воздухе даёт 2225 К,
  водород 2381 К, что сходится со справочными значениями;
- **кинетика в реакторе** идеального смешения: как меняются температура
  и состав во времени;
- **состав механизма**: какие вещества и сколько реакций в нём есть.

Механизмы берутся из комплекта Cantera: gri30 (природный газ, 53 вида,
325 реакций), h2o2 (водород), ir, додекан, вода и пар.

Это единственный модуль, где расчёт идёт по чужому механизму, а не по нашим
справочникам. Поэтому в результате всегда указано, какой механизм
использован и какой версии Cantera сделан расчёт.

## Выгрузка в LaTeX и DOCX

Результат можно забрать в текст, а не перепечатывать руками.

**LaTeX.** Под результатом есть кнопка «Копировать LaTeX». Она появляется
там, где есть формула или уравнение, и кладёт в буфер обмена готовую запись:

```
CuSO4*5H2O  ->  \mathrm{CuSO_{4}} \cdot 5\, \mathrm{H_{2}O}
MnO4-       ->  \mathrm{MnO_{4}}^-
2H2 + O2    ->  2\, \mathrm{H_{2}} + \mathrm{O_{2}} \rightarrow 2\, \mathrm{H_{2}O}
```

Уравнение разбирается тем же кодом, что и балансировщик, поэтому заряд иона
не путается с плюсом-разделителем: в `MnO4- + Fe2+ + H+ = ...` плюсов
ровно столько, сколько веществ.

Есть и вариант через пакет mhchem: `\ce{MnO4- + Fe2+ + H+ -> Mn2+ + Fe3+ + H2O}`.

**DOCX.** Меню «Файл» даёт два варианта: выгрузить весь журнал операций или
только текущий расчёт. В документ попадают значение, метод, ход расчёта,
предупреждения, источники и запись в LaTeX. Формулы и таблицы нормально
открываются в Word и LibreOffice.

Обе возможности необязательные: без `python-docx` программа работает,
а экспорт сам скажет, что установить.

## Школьная программа

Модули закрывают курс 8–11 классов, кроме органической химии.

**8 класс.** Степени окисления (с правилами для пероксидов и фторидов),
четыре типа реакций по числу и составу веществ, окислитель
и восстановитель, молярная масса и массовая доля, расчёты по уравнениям,
тепловой эффект, растворы, классы неорганических соединений
и систематические названия.

**9 класс.** Электронный баланс с полуреакциями и множителями, тип
химической связи по разнице электроотрицательностей, кристаллические
решётки, смещение равновесия по Ле Шателье, жёсткость воды с умягчением,
качественные реакции на ионы с поиском по реагенту и по признаку,
генетическая связь между классами.

**11 класс.** Строение вещества, скорость и равновесие, pH и гидролиз,
электролиз, коррозия.

Органическая химия не входит: там нужен отдельный движок на структурах,
а не на формулах.

## Источники данных

- Атомные массы и изотопы: IUPAC, CIAAW
- Термохимия: NIST-JANAF, справочник Глушко, CRC Handbook
- Полиномы Cp(T): Alexander Burcat, Branko Ruscic, Thermodynamic Data
  for Combustion and Air-Pollution Use (NASA, 950 веществ)
- Электродные потенциалы: CRC Handbook, Latimer
- Константы кислотности: IUPAC, справочник Лурье
- Произведения растворимости: CRC Handbook, NIST
- Радионуклиды: ICRP-107, AME2020, NUBASE2020 (через radioactivedecay)
- Физические константы: CODATA-2018, SI-2019

Источник указан в каждом результате, где используются справочные данные.
Это не формальность: по нему видно, откуда взялось число и где его границы.

## Что дали библиотеки

Три библиотеки закрыли то, что раньше считалось вручную и потому приближённо.

**Теплоёмкость как функция температуры.** В компактном справочнике Cp лежит
одним числом при 298 К, поэтому нагрев до 1500 К считался с постоянной
теплоёмкостью. Теперь на 950 веществ есть полиномы NASA из базы Burcat:
энтальпия и энтропия интегрируются по температуре, и тепловой эффект при
1000 К совпадает с таблицами JANAF. Если для какого-то участника полиномов
нет, программа откатывается на постоянную Cp и предупреждает.

**Неопределённость с учётом корреляций.** Раньше все величины считались
независимыми, поэтому разность двух одинаковых давала погрешность в √2 раза
больше одиночной. Теперь повторное использование величины учитывается:
разность тождественно равных равна нулю с нулевой погрешностью, а произведение
величины на себя даёт 2·x·σ вместо √2·x·σ.

**Распад настоящих нуклидов.** Раньше цепочка решалась численно по списку
периодов полураспада и про ветвления не знала ничего. Теперь доступны
1252 изотопа с реальными периодами, каналами распада и метастабильными
состояниями: Co-60 даёт Ni-60, а U-238 за 4.5 млрд лет проходит всю цепочку
до стабильного Pb-206.

## Пересборка справочников

Данные лежат снимками, поэтому в работе программа от сторонних библиотек
не зависит. Обновить снимки — две команды.

Элементы (нужен `mendeleev`):

```
python tools/build_elements.py
```

Полиномы Cp(T) (нужен `thermochem`, из него берётся BURCAT_THR.xml):

```
python tools/build_thermo_polynomials.py
```

Второй можно запустить и по явному пути к файлу базы:

```
python tools/build_thermo_polynomials.py --xml путь/к/BURCAT_THR.xml
```
