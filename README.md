# Alchemy — химический калькулятор

Калькулятор по химии, который считает то, что можно проверить. Справочники
в комплекте, интернет не нужен. ИИ-сервисов внутри нет, только свои движки.

## Авторы

**stffbn4k** — проект: что считаем и зачем.

**Диси** (DeepSeek AI), инженер-расчётчик — расчёты, движки, интерфейс.
За числа в этой программе отвечаю я.

Программа умеет отказывать. Нет вещества в справочнике — скажет и не
подставит похожее. Модель неприменима — тоже скажет и покажет, где
кончается её область.

Сейчас это **бета**: модули есть, числа сходятся, но часть поведения ещё
меняется. Номера версии нет намеренно — нечего нумеровать.

## Нашёл ошибку

Программа считает молча, поэтому об ошибке узнают только от человека,
который сверил ответ с бумагой. Если это ты — пиши.

- **Ошибка в расчёте** — [Issues](https://github.com/LMRHCKst/alchemy/issues/new/choose),
  шаблон «Ошибка в расчёте». Нужны три вещи: что введено, что ожидалось
  и откуда это известно, что выдала программа. Без источника ожидания
  разбирать нечего: программа может быть права.
- **Величина в справочнике не сходится с первоисточником** — шаблон
  «Ошибка в справочных данных». Это важнее ошибки в коде: от одной величины
  зависят все расчёты сразу.
- **Не уверен, баг это или нет** — в [Discussions](https://github.com/LMRHCKst/alchemy/discussions).
- **Чего не хватает** — шаблон «Предложение».

Подробнее: [docs/feedback.md](docs/feedback.md).

Сроков не обещаю: проект делается в свободное время, а вся идея программы
в том, чтобы не врать, включая обещания по датам.

## Как записывать формулы

Заряд понимается в трёх видах: `MnO4-`, `MnO4^-`, `MnO4{-}`.

Три формы нужны не для красоты. `Fe3+` и `NO3-` устроены одинаково, а значат
разное: ион железа(III) и нитрат. Разбираются по составу:

| Запись | Что означает | Правило |
|---|---|---|
| `Fe3+` | Fe³⁺ | один элемент — цифры это заряд |
| `NO3-` | NO₃⁻ | несколько элементов, одна цифра — индекс |
| `SO42-` | SO₄²⁻ | несколько элементов, две цифры — последняя заряд |
| `O2{-}` | O₂⁻ | скобки снимают любую двойственность |

Где смысл правда двусмысленный, пиши явно: `O{2-}` для заряда 2 или `O2{-}`
для заряда 1 при индексе 2.

Ещё понимает: `CuSO4*5H2O` и `CuSO4·5H2O` (гидраты), `Ca(OH)2` (скобки),
`[Cu(NH3)4]SO4` (комплексы), `Fe2O3(тв)` (состояние), `0.5O2` (дробный
коэффициент), `e-` (электрон), `SO4²⁻` (надстрочные цифры).

## Школьная программа

Модули закрывают курс 8–11 классов целиком.

**8 класс.** Степени окисления с правилами для пероксидов и фторидов, четыре
типа реакций, окислитель и восстановитель, молярная масса, расчёты
по уравнениям, тепловой эффект, растворы, классы соединений и названия.

**9 класс.** Электронный баланс, тип связи по разнице
электроотрицательностей, решётки, смещение равновесия, жёсткость воды,
качественные реакции на ионы, генетическая связь классов.

**10 класс, органика.** 18 классов от алканов до белков, гомологические ряды,
число изомеров у алканов и все типы изомерии, формула по продуктам сгорания,
62 уравнения реакций, 13 качественных проб, полимеры, переходы между
классами.

**11 класс.** Строение вещества, скорость и равновесие, pH и гидролиз,
электролиз, коррозия.

Класс определяется по формуле или названию. Если состав допускает два
класса, программа говорит прямо: `C3H6` — это и пропен, и циклопропан,
по одной формуле их не различить. Записанная структура снимает
неоднозначность: в `CH3COOH` видна группа COOH, значит кислота, а не
сложный эфир.

## Тесты

```
python -m unittest discover -s tests -t .
```

1017 тестов. Сверяют расчёты со справочными и экспериментальными значениями.

Отдельно есть ультрасложные тесты (`tests/test_hard.py`), которые проверяют
не числа, а инварианты: закон Гесса коммутирует с Кирхгофом при любой
температуре, масса и заряд сохраняются на реакциях с гигантскими
коэффициентами, формула восстанавливается из своих же продуктов сгорания,
осмос и криоскопия дают один фактор Вант-Гоффа.

Именно они нашли три ошибки в моих же формулах: дробные коэффициенты
в термохимии масштабировались неверно, галочка учёта активностей ничего
не переключала, а ярлык «сильная кислота» перебивал константу.

## Движки можно звать без интерфейса

```python
from alchemy.engines import thermo, acidbase, balancer

thermo.reaction_enthalpy("H2 + O2 = H2O(ж)").numeric()      # -571.66
acidbase.ph_of_acid("CH3COOH", 0.1).numeric()               # 2.89
balancer.balance("KMnO4 + HCl = KCl + MnCl2 + Cl2 + H2O").value
```

## Сборка exe

```
python -m venv buildenv
buildenv\Scripts\python.exe -m pip install PySide6-Essentials matplotlib ^
    numpy uncertainties radioactivedecay python-docx pyinstaller

buildenv\Scripts\python.exe -m PyInstaller --noconfirm --name Alchemy --windowed ^
    --add-data "alchemy/data;alchemy/data" ^
    --exclude-module tkinter --exclude-module cantera ^
    --exclude-module periodictable --exclude-module pytest ^
    --distpath dist --workpath build main.py
```

Готовое — `dist\Alchemy\Alchemy.exe`, 24 МБ, вся папка 257 МБ, запуск
0.6 секунды.

Две вещи, без которых не получится:

**Чистое окружение.** В системном Python стоит много всего, и PyInstaller
подхватывает `torch`, `tensorflow`, `yt_dlp` — сборка выходит на 3 ГБ вместо
257 МБ. Собирать только из пустого venv.

**`--add-data` обязателен.** Без него программа откроется, но при первом
расчёте скажет, что нет справочников. `loader.py` ищет JSON в `sys._MEIPASS`,
куда PyInstaller их распаковывает.

Nuitka не подошла: она компилирует `scipy` и `sympy`, которые тянет
`radioactivedecay`, и сборка идёт три часа вместо полутора минут.

Сборка в репозиторий не кладётся: `dist/`, `build/` и `buildenv/`
в `.gitignore`.

## Выгрузка в LaTeX и DOCX

Под результатом есть кнопка «Копировать LaTeX»:

```
CuSO4*5H2O  ->  \mathrm{CuSO_{4}} \cdot 5\, \mathrm{H_{2}O}
```

Меню «Файл» выгружает журнал или текущий расчёт в DOCX: значение, метод,
ход расчёта, предупреждения, источники. Без `python-docx` программа
работает, экспорт сам скажет, что установить.

## Источники данных

- Атомные массы и изотопы: IUPAC, CIAAW
- Термохимия: NIST-JANAF, справочник Глушко, CRC Handbook
- Полиномы Cp(T): Burcat, Ruscic (NASA, 950 веществ)
- Электродные потенциалы: CRC Handbook, Latimer
- Константы кислотности: IUPAC, справочник Лурье
- Произведения растворимости: CRC Handbook, NIST
- Радионуклиды: ICRP-107, AME2020, NUBASE2020
- Физические константы: CODATA-2018, SI-2019

Источник указан в каждом результате, где используются справочные данные:
по нему видно, откуда взялось число и где его границы.

## Структура

```
alchemy/
    core/       константы, единицы, результаты, парсер формул
    data/       справочники (JSON) и доступ к ним
    engines/    17 расчётных движков, про интерфейс не знают
    ui/         вкладки и их компоненты
    ui_qt/      главное окно, меню, экспорт
tests/          1017 автотестов
tools/          генераторы справочников
_legacy/        прежняя версия программы
```

Расчёты отделены от интерфейса: движки можно звать из своего кода, они
не зависят ни от Qt, ни от окон. Справочники лежат снимками JSON, поэтому
в работе программа от сторонних библиотек не зависит.
